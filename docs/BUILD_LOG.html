The current core loop

01 // Route

Use touch halves or A/D to work the flippers. The ball has fixed-step physics, swept flipper contacts, material-specific restitution, and an authoritative drain.

02 // Salvage

Hit six targets, generators, pulse bumpers, armored bumpers, and relay gates. Chain contacts increase Score while Charge remains the build currency.

03 // Commit

Between descents, spend Charge on hydraulic arms, extended arms, or hull repair—or take a free survival/economy modification.

Build timeline

Prototype 01–20

Make the table playable

Established portrait touch controls, fixed 60Hz physics, flippers, targets, stability, three-stage progression, win/loss/reset, and the industrial visual language.

Prototype 21–27

Make the lower table honest

Aligned the drain geometry, removed edge rescue loops, sealed the funnel-to-wall seam, reserved the mobile label band, and corrected short-viewport Canvas sizing.

Prototype 28–33

Make impact feel intentional

Added live physics tuning, stronger active contacts, anti-hug separation, upward flipper escape, swept collision sampling, angled respawns, and removed the bottom-center bumper.

Prototype 34–40

Expand the run

Added three layouts, pulse and armored bumper variants, relay gates, layout-specific target banks, Charge-funded flipper modules, repair, Charge Chain scoring, and a two-hit armor breach.

Prototype 41–42

Refine the feel

Stopped stale swept contacts from pulling exiting balls back onto the blade, corrected gravity to 0.07, damped terrain, and strengthened bumper/flipper impact response.

Prototype 43–44

Elementalize the build

Added moving-tip flipper sweeps, four locally generated elemental emblems, Fire/Water/Earth/Air upgrade modules, and full-viewport left/right touch input that still leaves UI cards tappable.

Prototype 45

Attune the hinges

Moved elemental power out of physics upgrades and into flipper hinge modules. Cradled balls now collect stacking, decaying imprints that react with affinity-matched targets, bumpers, and relay gates.

Prototype 46

Catch the moving blade

Made current-frame moving-flipper overlap authoritative at the midpoint sweep and returned immediately after drain recovery so replacement balls cannot be invalidated by the old frame.

Prototype 47

Close the crossing gaps

Expanded moving collision to five interpolation samples per fixed update and return early after target completion, protecting both fast tip crossings and the respawn state path.
